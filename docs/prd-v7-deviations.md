# PRD v7 대비 의도적 이탈 사항 (2026-09-11)

기준 문서: `docs/prd/GreenScan_PRD_v7.md`

디자인팀 목업(화면 3종: 홈/AI분석하기/분석결과)을 검토하면서, PM이 PRD v7의 일부 원칙을 **의도적으로** 벗어나기로 결정한 항목을 기록한다. PRD 본문은 수정하지 않고, 이 문서가 "무엇을, 왜, 어떤 조건으로 벗어났는지"의 단일 근거가 된다. BE-A/B/C, FE, 디자인 모두 이 문서 기준으로 작업할 것.

## 유지된 것 (PRD v7 그대로)

- 건물 규모/용도: 대표 공간 1개, 주거(단독·다가구/아파트)만. **1,000㎡+ 상업·업무·공공 건물 지원은 반영하지 않음.**
- "스캔" 버튼: 라이다/RoomPlan이 아니라 단순 카메라 촬영 버튼임을 확인 — PRD와 충돌 없음.
- 원본 사진 서버 미저장 원칙은 유지.

## 의도적으로 벗어난 것

### 1. 등급/우선순위 배지 (PRD 1.3, 7.5 위반)

PRD는 "근거 없는 낮음·보통·높음 위험도 등급은 표시하지 않는다"고 명시했지만, 디자인팀 시안의 `LV.3 좋음`, 개선 우선순위 `긴급/주의/양호` 배지 스타일을 **가독성 때문에 유지하기로 결정**.

- **조건부 허용**: 결과 화면에 "이 등급/우선순위는 참고용 추정치이며 실제와 다를 수 있습니다" 류의 부정확성 고지를 반드시 함께 표시한다. 고지 없이 이 표현만 단독으로 쓰지 않는다.
- 등급 산정 로직(무엇을 LV.3으로 볼지, 긴급/주의/양호의 경계)은 이 문서에서 확정하지 않는다. **BE-C가 계산 엔진 설계 시 정책값으로 확정** — 임의 수치를 프론트에 하드코딩하지 않는다.

### 2. 건물 전체 에너지 사용량 표시 (PRD 1.3 위반)

디자인팀 시안의 "예상 연간 에너지 사용량(개선 전/후)" 카드는 유지하되, **실측 건물 전체 사용량을 예측/검증한 것처럼 표현하지 않는다.** 우리 계산 모델(대표 공간 기준 추정 열손실)에서 나온 값을 "예상" 표현으로 감싸 보여주는 것으로 재정의한다 — 데이터 출처는 여전히 대표 공간 1개 추정치다.

### 3. 견적/비용 표시 (PRD 7.5, 11장 제외 대상 위반)

PRD는 "비용과 견적 금액은 표시하지 않는다"와 "시공비, 견적, 시공업체 연결"을 명시적 제외 기능으로 뒀지만, 홈 화면의 "최근 분석한 방" 목록과 결과 화면에 **러프 범위 텍스트 형태의 견적을 표시하기로 결정**.

- **정밀 견적 모델(단가 테이블, 지역별 단가 등)은 만들지 않는다.** "약 350~550만원" 같은 넓은 범위 텍스트만 쓴다.
- 반드시 "실제 시공비는 현장 확인 후 별도 안내됩니다" 같은 비확정 고지를 동반한다.
- 실제 범위 숫자 자체는 근거 데이터가 없어 **이 문서에서 확정하지 않음 — 정책 확정 필요**. 지금 목업에는 자리만 잡아두는 placeholder 텍스트를 쓴다.

### 4. 진단 이력 저장 (PRD 3.2, 5.1 위반)

PRD는 "계정, 로그인, 프로필, 장기 진단 이력"을 제외 대상으로 뒀고 서버 측 이력 저장을 하지 않는다고 했지만, 홈 화면에 "최근 분석한 건물/방" 이력을 보여주기로 결정.

- 계정/로그인은 여전히 없음 — 이력은 로그인 기반이 아니다.
- 저장 방식(디바이스/브라우저 로컬 저장 vs 서버 익명 식별자 저장, on/off 토글 여부)은 **BE에서 DB 작업 진행 중** — FE는 이 결정을 기다리지 않고, 우선 UI만 목업 데이터로 자리를 잡아둔다. 실제 연동은 BE가 이력 API/DB 스키마를 확정한 뒤 진행한다.

### 5. 벽체 이상 흔적 확장 아이디어 (PRD 위반 아님, 향후 검토)

"누수" 진단 예시는 폐기. 대신 "곰팡이로 추정되는 흔적이 있으면 습도가 높다는 안내를 포함할 수 있다"는 확장 아이디어를 검토 대상으로 기록. PRD의 "사진 AI는 원인을 확정하지 않는다" 원칙과 상충하지 않게, 여전히 **후보/안내 수준(현장 점검 권장)으로만 다루고 U값·열손실 계산에는 영향 주지 않는다.** 지금 당장 구현 범위는 아니고, `visible_anomaly_candidate`류 스키마 확장 검토 항목으로만 남긴다.
